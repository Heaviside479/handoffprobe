## Maintenance rule

- Keep canonical information in the document that owns it; this index is navigation.
- Do not mass-move historical evidence solely for cosmetic organization.
- When a new top-level file is added under `docs/`, classify and link it here.
- Preserve immutable release and research provenance.
- Documentation cleanup alone does not authorize a release, version change or new stable attack.
